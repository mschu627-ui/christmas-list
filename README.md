# My Christmas List

Open index.html in a modern browser to try the wishlist. Add a gift with a photo upload or direct image URL, shopping link, size, colour, price in CAD, and notes. Edit or remove gifts from their cards.

The wishlist saves in the browser on the current device. It does not sync between browsers or upload gifts to GitHub. A list created locally is separate from a list created on the published URL.

## Publish on GitHub Pages

1. Create a public GitHub repository named christmas-list.
2. Extract the ZIP. In the repository, choose Add file > Upload files. Upload the files inside the christmas-list folder so index.html is at the repository root. Commit the files.
3. Open Settings > Pages. Under Source, choose Deploy from a branch. Select main and / (root), then Save.
4. Once deployment finishes, open the site URL shown under Settings > Pages.

Publishing instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
